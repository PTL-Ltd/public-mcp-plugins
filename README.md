# PTL Public MCP Plugins

This public repository distributes metadata-only client packages for three read-only, remotely hosted MCP servers operated by Providing Technical Leadership Kft.

The MCP servers execute only on their public HTTPS endpoints. This repository does not contain server implementation code, website source code, private corpora, credentials, access codes, challenge tokens or locally executable MCP commands.

The complete package set will be added through a reviewed pull request.
